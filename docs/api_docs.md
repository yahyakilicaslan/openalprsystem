# Evo Teknoloji ANPR API Dokümantasyonu

Bu doküman, sistemin backend servisleri için mevcut olan tüm API endpoint'lerini listeler.

## Siteler (`/api/sites`)

- `POST /` - Yeni bir site ekler.
- `GET /` - Tüm siteleri listeler.
- `GET /{id}` - Belirli bir siteyi getirir.
- `PUT /{id}` - Belirli bir siteyi günceller.
- `DELETE /{id}` - Belirli bir siteyi siler.
